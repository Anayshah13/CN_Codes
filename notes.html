Show that you can read a machine’s name, DNS, routes, ARP cache, and interface addresses.

What each command answers

How to read the output

  • nslookup. “Non-authoritative answer” means the reply came from a cache, not from the domain’s own DNS server. Several A records means several IPv4 addresses. Addresses with colons are IPv6.
  • route. UG on 0.0.0.0 is the default gateway. U alone means a directly connected network. Iface is the NIC used, such as wlo1.
  • arp. One row maps the gateway’s IP to its Ethernet MAC. The cache is learned, not configured by hand.
  • ip addr. lo is 127.0.0.1, used only inside this machine. UP means the interface is on. /24 means the first 24 bits are the network.
Say this. DNS turns a name into an IP. ARP turns an IP on the local LAN into a MAC. The routing table decides which next hop gets the packet.

Viva

Why can nslookup show many addresses for one name?

The name has several A or AAAA records. The client may use any of them. That is how large sites spread load.

What is the default route?

Destination 0.0.0.0/0. Anything that does not match a more specific route is sent to that gateway.

Where does ARP sit?

It binds a network-layer IP address to a data-link MAC address on the same LAN. It is not used to cross the internet; each hop does its own ARP.

Experiment 4 · Data link

Hamming code

Detect and correct a single-bit error with even parity bits placed at powers of two.

Layout

Number bits from the right, starting at 1. Positions 1, 2, 4, 8, … are parity. Every other position is data, filled left to right from the message. Use even parity: each parity bit is set so the bits it checks XOR to 0.

Parity bit p checks every position whose binary number has that bit set. Position 1 checks 1, 3, 5, 7, … Position 2 checks 2, 3, 6, 7, … Position 4 checks 4, 5, 6, 7, …

Redundant bits r satisfy 2r ≥ m + r + 1, where m is the number of data bits.

Example you can write on paper

Data 1011 needs r = 3, so the codeword is 7 bits. Positions 7→1 print as 1100110.

Position7654321
Roledatadatadatap4datap2p1
Bit1100110

Flip position 4 and the word becomes 1101110. The receiver recomputes the three parity checks. A failed check adds that parity’s position into the syndrome. Syndrome 4 means “flip position 4”. The corrected word is 1100110 again. Syndrome 0 means no error.

Say this. One wrong bit is corrected. Two wrong bits make a syndrome that points at the wrong place, so Hamming as used here is single-error correction.

File part of the lab

The file is split into 16-bit blocks and again into 32-bit blocks. About one block in twenty is given a single flipped bit. Each block is encoded, the syndrome is computed, and that bit is flipped back. The table reports total blocks, injected errors, and corrections.

import random
import sys
from pathlib import Path

hamming_encode — Parity bits sit at positions 1, 2, 4, 8. Data fills the other positions. Each parity bit is set so the bits it checks XOR to 0.

def hamming_encode(data: str) -> str:
    if not data or any(bit not in "01" for bit in data):
        raise ValueError("data must be a binary string")
    m = len(data)
    r = 0
    while (1 << r) < m + r + 1:
        r += 1
    n = m + r
    code = [0] * (n + 1)  # 1-based
    j = 0
    for pos in range(1, n + 1):
        if pos & (pos - 1) == 0:
            continue
        code[pos] = int(data[j])
        j += 1
    pos = 1
    while pos <= n:
        parity = 0
        for i in range(1, n + 1):
            if i & pos:
                parity ^= code[i]
        code[pos] = parity
        pos <<= 1
    return "".join(str(code[pos]) for pos in range(n, 0, -1))

syndrome — The receiver repeats those parity checks. Add the position of every check that fails. That sum is the bad bit. 0 means no error.

def syndrome(received: str) -> int:
    n = len(received)
    code = [0] * (n + 1)
    for pos in range(1, n + 1):
        code[pos] = int(received[n - pos])
    error_position = 0
    pos = 1
    while pos <= n:
        parity = 0
        for i in range(1, n + 1):
            if i & pos:
                parity ^= code[i]
        if parity:
            error_position += pos
        pos <<= 1
    return error_position

correct — Flips the bit the syndrome names. Position 1 is the rightmost bit of the printed codeword.

def correct(received: str, error_position: int) -> str:
    if error_position == 0:
        return received
    bits = list(received)
    index = len(bits) - error_position
    if index < 0 or index >= len(bits):
        return received
    bits[index] = "1" if bits[index] == "0" else "0"
    return "".join(bits)

flip_one — Demo only. Flips one random bit so you can watch the correction.

def flip_one(codeword: str) -> tuple[str, int]:
    bits = list(codeword)
    index = random.randrange(len(bits))
    bits[index] = "1" if bits[index] == "0" else "0"
    return "".join(bits), len(bits) - index

explain_block — Prints data, codeword, the damaged word, the syndrome, and the corrected word for one short string.

def explain_block(data: str, force_error: bool = True) -> None:
    encoded = hamming_encode(data)
    print(f"Data        : {data}")
    print(f"Hamming code: {encoded}")
    if not force_error:
        position = syndrome(encoded)
        print(f"Syndrome    : {position} (0 means no error)")
        return
    received, flipped_pos = flip_one(encoded)
    position = syndrome(received)
    fixed = correct(received, position)
    print(f"Received    : {received}  (flipped position {flipped_pos})")
    print(f"Syndrome    : {position}")
    print(f"Corrected   : {fixed}")
    print("Match       :", "yes" if fixed == encoded else "no")

process_file — Splits a file into 16-bit or 32-bit blocks. About one block in twenty gets a single-bit error, then that bit is corrected.

def process_file(data: bytes, frame_size: int) -> tuple[int, int, int]:
    binary = "".join(format(byte, "08b") for byte in data)
    padding = (frame_size - len(binary) % frame_size) % frame_size
    binary += "0" * padding
    total_blocks = len(binary) // frame_size
    error_blocks = max(1, total_blocks // 20)
    selected = set(random.sample(range(total_blocks), min(error_blocks, total_blocks)))
    errors = 0
    corrections = 0
    shown = 0
    for block in range(total_blocks):
        start = block * frame_size
        payload = binary[start : start + frame_size]
        encoded = hamming_encode(payload)
        received = encoded
        if block in selected:
            received, _ = flip_one(encoded)
            errors += 1
        position = syndrome(received)
        corrected = correct(received, position)
        if position != 0:
            corrections += 1
        if shown < 3:
            print(f"  block {block}: data {payload}")
            print(f"           code {encoded}")
            if received != encoded:
                print(f"           rx   {received} -> {corrected}")
            shown += 1
    if total_blocks > shown:
        print(f"  ... {total_blocks - shown} more blocks")
    return total_blocks, errors, corrections

Viva

Why powers of two?

Each data bit then falls into a unique combination of parity checks, so the pattern of failed checks is the binary address of the bad bit.

Even or odd parity?

This program uses even parity. The check XOR, including the parity bit, is 0 when the bits are correct.

Does it fix a burst of errors?

No. A second error moves the syndrome off the real positions.

CRC

Detect errors by appending the remainder of a modulo-2 division by a generator polynomial.

Sender and receiver

  1. Generator of length k corresponds to a polynomial. Example: x3 + x2 + 1 = 1101.
  2. Append k−1 zeros to the message.
  3. Divide with XOR instead of subtraction. The remainder has k−1 bits.
  4. Send message + remainder. The receiver divides the whole word by the same generator and appends no extra zeros.
  5. Remainder 0 means no detected error. Any other remainder means the word is damaged. CRC does not tell you which bit to flip.
Say this. The aim sheet says “detection and correction”, but the method you implemented only detects. Correction would need a retransmission or a different code, such as Hamming.

from __future__ import annotations

import sys
from pathlib import Path

xor_div — Sender step. Stick k−1 zeros on the message and divide by the generator using XOR, not subtraction. The last k−1 bits are the remainder.

def xor_div(data: str, generator: str) -> str:
    """Modulo-2 division. Returns the remainder of length len(generator) - 1."""
    if not generator or generator[0] != "1":
        raise ValueError("generator must be a binary string starting with 1")
    if any(bit not in "01" for bit in data + generator):
        raise ValueError("data and generator must be binary")
    width = len(generator)
    register = list(data + "0" * (width - 1))
    for i in range(len(register) - width + 1):
        if register[i] != "1":
            continue
        for j in range(width):
            register[i + j] = "0" if register[i + j] == generator[j] else "1"
    return "".join(register[-(width - 1) :])

check — Receiver step. Divide the received word by the same generator. Do not add extra zeros.

def check(received: str, generator: str) -> str:
    """Divide an already-encoded word. Do not append extra zeros."""
    width = len(generator)
    register = list(received)
    if len(register) < width:
        return received.zfill(width - 1)
    for i in range(len(register) - width + 1):
        if register[i] != "1":
            continue
        for j in range(width):
            register[i + j] = "0" if register[i + j] == generator[j] else "1"
    return "".join(register[-(width - 1) :])

encode — What is sent: the original message with the remainder stuck on the end.

def encode(message: str, generator: str) -> tuple[str, str]:
    remainder = xor_div(message, generator)
    return remainder, message + remainder

report — Prints the remainder, the sent word, and Valid or Invalid.

def report(message: str, generator: str, received: str | None = None) -> None:
    remainder, sent = encode(message, generator)
    print(f"Message     : {message}")
    print(f"Generator   : {generator}")
    print(f"Remainder   : {remainder}")
    print(f"Sent data   : {sent}")
    word = received if received is not None else sent
    syndrome = check(word, generator)
    print(f"Received    : {word}")
    print(f"Check rem.  : {syndrome}")
    print("Result      :", "Valid" if int(syndrome, 2) == 0 else "Invalid")

flip — Flips one bit so a good codeword becomes a bad one.

def flip(word: str, index: int) -> str:
    bits = list(word)
    bits[index] = "1" if bits[index] == "0" else "0"
    return "".join(bits)

file_crc — CRC on 32-bit blocks of a file. The first block is corrupted on purpose so the check prints Invalid.

def file_crc(path: Path, generator: str = "110101") -> None:
    raw = path.read_bytes()
    bits = "".join(format(byte, "08b") for byte in raw)
    block = 32
    padding = (block - len(bits) % block) % block
    bits += "0" * padding
    print(f"\nFile: {path}")
    print(f"Bits: {len(bits)}   block: {block}   generator: {generator}")
    bad = 0
    shown = 0
    blocks = len(bits) // block
    for n in range(blocks):
        payload = bits[n * block : (n + 1) * block]
        remainder, sent = encode(payload, generator)
        received = sent
        # Corrupt the first block so the check is visible.
        if n == 0:
            received = flip(sent, 3)
        syndrome = check(received, generator)
        ok = int(syndrome, 2) == 0
        if not ok:
            bad += 1
        if shown < 2:
            print(f"Block {n}: remainder {remainder}  check {syndrome}  {'Valid' if ok else 'Invalid'}")
            shown += 1
    if blocks > shown:
        print(f"... {blocks - shown} more blocks")
    print(f"Blocks with a detected error: {bad} of {blocks}")

Viva

Why XOR?

Modulo-2 arithmetic has no carry. Addition and subtraction are the same operation, which is XOR.

Why can a clever error still pass?

If the error pattern is a multiple of the generator, the remainder is still 0. A good generator makes that rare for short bursts.

Where is the CRC usually placed?

In the trailer, after the payload, because the remainder is computed over the data that precedes it.

The code

exp6_vlsm.py — Designs the VLSM tables: largest network first, from the given address block.

Top of the file — Uses the standard library IP module so the network, first host, last host, and broadcast are real addresses.

"""Experiment 6: VLSM subnet design.

Largest network is allocated first from the given block.
Each subnet reserves two addresses: network id and broadcast.

Run: python exp6_vlsm.py
"""

from __future__ import annotations

import ipaddress

prefix_for_hosts — A subnet needs hosts + 2 addresses (network id and broadcast). Round that up to a power of two. Prefix = 32 − log2(size).

def prefix_for_hosts(hosts: int) -> int:
    if hosts < 1:
        raise ValueError("each network needs at least 1 host")
    needed = hosts + 2
    size = 1
    while size < needed:
        size *= 2
    return 32 - (size.bit_length() - 1)

design — Sorts requirements largest first and walks forward through the block. A /25 must start on a 128-address boundary, which is why the big one goes first.

def design(base: str, requirements: list[tuple[str, int]]) -> tuple[list[dict], int, str]:
    network = ipaddress.ip_network(base, strict=False)
    ordered = sorted(requirements, key=lambda item: item[1], reverse=True)
    cursor = int(network.network_address)
    end = int(network.broadcast_address)
    rows = []
    for name, hosts in ordered:
        prefix = prefix_for_hosts(hosts)
        size = 2 ** (32 - prefix)
        if cursor + size - 1 > end:
            raise ValueError(f"{name} does not fit in {network}")
        # Largest-first allocation stays aligned when the block itself is aligned.
        subnet = ipaddress.ip_network((cursor, prefix), strict=False)
        hosts_iter = subnet.hosts()
        first = next(hosts_iter)
        last = first
        for last in subnet.hosts():
            pass
        rows.append(
            {
                "name": name,
                "hosts": hosts,
                "cidr": f"{subnet.network_address}/{prefix}",
                "network": str(subnet.network_address),
                "first": str(first),
                "last": str(last),
                "broadcast": str(subnet.broadcast_address),
                "mask": str(subnet.netmask),
                "prefix": prefix,
                "size": size,
            }
        )
        cursor += size
    unused = end - cursor + 1
    return rows, unused, str(network)

Experiment 8 · Transport

TCP sockets and selection sort

Two clients each send an integer array. The server sorts each array, then sorts the merged array, and sends both results back.

Why TCP

  • Connection-oriented: connect does a three-way handshake before any array is sent.
  • Reliable byte stream: sendall / recv deliver the bytes in order. The program still frames messages with a newline because TCP does not preserve your “one send = one recv”.
  • Server listens on 0.0.0.0:8000, so it accepts clients on this machine at 127.0.0.1.

Order of messages

  1. Client sends a JSON list, for example [5, 1, 4], followed by \n.
  2. Server stores it and waits until both clients have sent.
  3. Case 1: selection-sort a copy of that client’s array. Send {"case": 1, "individual_sorted": [...]}.
  4. Case 2: one thread merges client 1’s list with client 2’s list, selection-sorts it, and both clients receive merged_sorted.

Selection sort, one pass

For index i, assume arr[i] is the minimum. Scan the rest. If a smaller value is found, remember its index. Swap it with arr[i] if the index changed. After pass i, the first i+1 items are in their final place. The server prints every comparison so you can narrate a pass.

Example: [5, 1, 4] → pass 1 swaps 5 and 1 → [1, 5, 4] → pass 2 swaps 5 and 4 → [1, 4, 5].

LineReader — TCP is a byte stream. One recv can contain both JSON replies, or only half of one. This reads until a newline, which is the message boundary.

class LineReader:
    def __init__(self, sock: socket.socket) -> None:
        self.sock = sock
        self.buffer = b""

    def read_json(self):
        while b"\n" not in self.buffer:
            chunk = self.sock.recv(4096)
            if not chunk:
                return None
            self.buffer += chunk
        line, self.buffer = self.buffer.split(b"\n", 1)
        if not line:
            return None
        return json.loads(line.decode())

selection_sort — Pass i finds the smallest value from index i to the end and swaps it into index i. Every comparison is printed so you can narrate a pass.

def selection_sort(arr: list[int], name: str) -> list[int]:
    lines = [f"\n{'=' * 60}", f"SELECTION SORT: {name}", "=" * 60, f"Original Array: {arr}"]
    n = len(arr)
    for i in range(n - 1):
        min_index = i
        lines.append(f"\nPASS {i + 1}")
        lines.append(f"Starting Array: {arr}")
        lines.append(f"Assume minimum = {arr[min_index]} at index {min_index}")
        for j in range(i + 1, n):
            lines.append(f"Compare {arr[j]} with {arr[min_index]}")
            if arr[j] < arr[min_index]:
                min_index = j
                lines.append(f"New minimum found: {arr[min_index]} at index {min_index}")
        if min_index != i:
            lines.append(f"Swap {arr[i]} and {arr[min_index]}")
            arr[i], arr[min_index] = arr[min_index], arr[i]
        else:
            lines.append("No swap required.")
        lines.append(f"Array after Pass {i + 1}: {arr}")
    lines.append(f"\nFinal Sorted Array: {arr}")
    with print_lock:
        print("\n".join(lines))
    return arr

def handle_client(client_socket: socket.socket, address, client_number: int) -> None:
    global merged_sorted
    reader = LineReader(client_socket)
    try:
        array = reader.read_json()
        if not isinstance(array, list):
            print(f"Client {client_number} sent no array.")
            return
        array = [int(x) for x in array]
        print(f"\nClient {client_number} connected from {address}")
        print(f"Array received: {array}")

        with lock:
            client_arrays[client_number] = array
            if len(client_arrays) == 2:
                both_received.set()

        print(f"Client {client_number} stored. Waiting for the other client...")
        both_received.wait()

        individual = selection_sort(array.copy(), f"Client {client_number}")
        send_json(client_socket, {"case": 1, "individual_sorted": individual})

        with lock:
            if merged_sorted is None:
                merged = client_arrays[1] + client_arrays[2]
                print(f"\nClient 1 Array: {client_arrays[1]}")
                print(f"Client 2 Array: {client_arrays[2]}")
                print(f"Merged Array: {merged}")
                merged_sorted = selection_sort(merged.copy(), "MERGED ARRAY")
            result = merged_sorted

        send_json(client_socket, {"case": 2, "merged_sorted": result})
        print(f"Client {client_number} connection closed.")
    except (OSError, json.JSONDecodeError, ValueError, KeyError) as exc:
        print(f"Client {client_number} error: {exc}")
    finally:
        client_socket.close()

UDP group chat

Several clients talk through one UDP server. There is no connection, only datagrams.

How a client is known

UDP has no handshake. The server remembers each sender as the pair (IP, port) from recvfrom. The first datagram from that pair is the username. Later datagrams are chat text. bye deletes that pair and tells the others.

A message is sent to every stored address except the sender. The sender already has the text on their own screen.

  • One socket, SOCK_DGRAM, aimed at 127.0.0.1:5010 unless you pass another host.

Say this. TCP would give one ordered byte stream per client. UDP gives independent datagrams. The chat works only because the application itself keeps the address book and decides what a “join” is.

def main() -> None:

    server.bind((HOST, PORT))
    clients: dict[tuple[str, int], str] = {}

    print("=== UDP GROUP CHAT SERVER ===")
    print(f"Server is running on port {PORT}...")
    print("Press Ctrl+C to stop.")

    try:
        while True:
            data, address = server.recvfrom(1024)
            message = data.decode(errors="replace").strip()
            if not message:
                continue

            if address not in clients:
                clients[address] = message
                print(f"[JOIN] {message} {address} connected.")
                alert = f"\n*** {message} has joined the chat room! ***".encode()
                for other in clients:
                    if other != address:
                        server.sendto(alert, other)
                continue

            username = clients[address]
            if message.lower() == "bye":
                print(f"[LEAVE] {username} {address} disconnected.")
                del clients[address]
                alert = f"\n*** {username} has left the chat room. ***".encode()
                for other in clients:
                    server.sendto(alert, other)
                continue

            print(f"[{username}]: {message}")
            outgoing = f"\n[{username}]: {message}".encode()
            for other in list(clients):
                if other != address:
                    server.sendto(outgoing, other)
    except KeyboardInterrupt:
        print("\nServer stopped.")
    finally:
        server.close()

Experiment 10 · Data link

Stop-and-Wait ARQ

Send one packet, wait for its ACK, and retransmit if the data or the ACK is lost.

Rules

  • The sender does not transmit packet n+1 until ACK for packet n has arrived.
  • Sequence numbers alternate 0, 1, 0, 1. Packet 1 is sequence 0 because (id − 1) % 2.
  • A lost data frame: the receiver never ACKs. The sender waits timeout after the data should have arrived, then sends the same packet again.
  • A lost ACK: the receiver already has the data, but the sender still times out and retransmits. The sequence number lets the receiver recognise the duplicate.
  • In this program each listed packet id is dropped once, on its first try. The retry gets through.

Trace to memorise

Four packets, data 2 lost, ACK 3 lost. Times use data = 0.50 and ACK = 0.25, timeout = 2.00.

Event — sequence is 0 or 1. Packet 1 is sequence 0, packet 2 is sequence 1, because only two numbers are needed when the window is 1.

@dataclass(frozen=True)
class Event:
    packet_id: int
    packet_type: str
    start: float
    end: float
    status: str

    @property
    def sequence(self) -> int:
        return (self.packet_id - 1) % 2

simulate — Sends a packet and waits for its ACK. A listed data loss or ACK loss happens once, on the first try. The sender then waits out the timeout and sends that packet again.

def simulate(
    packet_count: int = 20,
    data_losses: list[int] | None = None,
    ack_losses: list[int] | None = None,
    timeout: float = 2.0,
    data_time: float = 0.5,
    ack_time: float = 0.25,
) -> list[Event]:
    """Build a Stop-and-Wait timeline.

    Each listed packet id is lost once (first transmission only), matching
    the GUI: a data loss and an ACK loss are separate one-shot events.
    """
    if packet_count < 1:
        raise ValueError("packet_count must be at least 1")
    data_loss_set = set(data_losses or ())
    ack_loss_set = set(ack_losses or ())
    events: list[Event] = []
    now = 0.0
    used_data: set[int] = set()
    used_ack: set[int] = set()

    for packet_id in range(1, packet_count + 1):
        attempt = 0
        while True:
            attempt += 1
            note = "" if attempt == 1 else f" (retry {attempt - 1})"
            start = now
            end = start + data_time
            if packet_id in data_loss_set and packet_id not in used_data:
                used_data.add(packet_id)
                events.append(Event(packet_id, "DATA", start, end, "LOST" + note))
                now = end + timeout
                events.append(
                    Event(
                        packet_id,
                        "TIMEOUT",
                        end,
                        now,
                        f"No ACK; retransmit packet {packet_id}",
                    )
                )
                continue

            events.append(Event(packet_id, "DATA", start, end, "DELIVERED" + note))
            ack_start = end
            ack_end = ack_start + ack_time
            if packet_id in ack_loss_set and packet_id not in used_ack:
                used_ack.add(packet_id)
                events.append(Event(packet_id, "ACK", ack_start, ack_end, "LOST"))
                now = ack_end + timeout
                events.append(
                    Event(
                        packet_id,
                        "TIMEOUT",
                        ack_end,
                        now,
                        f"ACK lost; retransmit packet {packet_id}",
                    )
                )
                continue

            events.append(Event(packet_id, "ACK", ack_start, ack_end, "RECEIVED"))
            now = ack_end
            break
    return events

parse_ids — Turns the command-line text 2,4 into the packet ids to drop.

def parse_ids(text: str) -> list[int]:
    text = text.strip()
    if not text or text == "-":
        return []
    return [int(part) for part in text.split(",") if part.strip()]

print_trace — Prints the time, sequence, type, and status, then counts deliveries, losses, and timeouts.

def print_trace(events: list[Event]) -> None:
    print(f"{'Time':<14} {'Seq':<4} {'Type':<8} {'Packet':<8} Status")
    print("-" * 72)
    for event in events:
        span = f"{event.start:.2f}-{event.end:.2f}"
        seq = "-" if event.packet_type == "TIMEOUT" else str(event.sequence)
        print(f"{span:<14} {seq:<4} {event.packet_type:<8} {event.packet_id:<8} {event.status}")

    delivered = [e for e in events if e.packet_type == "DATA" and e.status.startswith("DELIVERED")]
    lost = [e for e in events if "LOST" in e.status]
    timeouts = [e for e in events if e.packet_type == "TIMEOUT"]
    print()
    print(f"Data deliveries : {len(delivered)}")
    print(f"Losses          : {len(lost)}")
    print(f"Timeouts        : {len(timeouts)}")
    if events:
        print(f"Total time      : {events[-1].end:.2f}")

_process_event — Updates sender and receiver state from that row: delivered, lost, or timeout.

    def _process_event(self, event: Event):
        # Check dynamic error injection
        is_lost = event.status.startswith("LOST")
        if self.inject_drop_data and event.packet_type == "DATA" and not is_lost:
            is_lost = True
            self.inject_drop_data = False
        if self.inject_drop_ack and event.packet_type == "ACK" and not is_lost:
            is_lost = True
            self.inject_drop_ack = False

        seq = str(event.packet_id % 2)

        # Update stats
        tag = "DATA_OK"
        if event.packet_type == "DATA":
            if "retry" in event.status:
                self.stat_retries += 1
                tag = "RETRY"
            else:
                self.stat_sent += 1
            if is_lost:
                self.stat_data_lost += 1
                tag = "LOST"
        elif event.packet_type == "ACK":
            if is_lost:
                self.stat_ack_lost += 1
                tag = "LOST"
            else:
                self.stat_delivered = max(self.stat_delivered, event.packet_id)
                tag = "ACK_OK"
        elif event.packet_type == "TIMEOUT":
            self.stat_timeouts += 1
            tag = "TIMEOUT"

        self._update_stat_cards()

        # Add row to Event Log Treeview
        item_id = self.tree_log.insert("", tk.END, values=(
            f"{event.start:.2f}s",
            f"#{event.packet_id}",
            event.packet_type,
            event.status
        ), tags=(tag,))
        self.tree_log.see(item_id)

        # Draw onto Space-Time Ladder Diagram
        self._add_ladder_event(event, self.current_event_idx, is_lost)

        # Trigger animated packet transfer
        self._start_packet_animation(event, seq, is_lost)

    def _draw_particles(self):
        c = self.canvas_channel
        new_particles = []
        for p in self.particles:
            p["x"] += p["vx"]
            p["y"] += p["vy"]
            p["life"] -= 0.1
            if p["life"] > 0:
                rad = max(1, int(p["life"] * 4))
                c.create_oval(p["x"] - rad, p["y"] - rad, p["x"] + rad, p["y"] + rad,
                              fill=p["color"], outline="")
                new_particles.append(p)
        self.particles = new_particles

    def _spawn_explosion(self, x, y, color):
        for i in range(16):
            angle = (i / 16.0) * 2 * math.pi
            spd = 2.0 + (i % 3) * 1.5
            self.particles.append({
                "x": x,
                "y": y,
                "vx": math.cos(angle) * spd,
                "vy": math.sin(angle) * spd,
                "life": 1.0,
                "color": color
            })

    def _parse_inputs(self):
        try:
            count = int(self.ent_count.get().strip() or "20")
            if count < 1:
                raise ValueError("Packet count must be at least 1.")
        except ValueError:
            messagebox.showerror("Invalid Input", "Please enter a valid positive number for Packet Count.")
            return None

        # Parse Data Losses
        raw_data = self.ent_data_loss.get().strip()
        data_losses = set()
        if raw_data and raw_data != "0":
            try:
                data_losses = {int(x.strip()) for x in raw_data.split(",") if x.strip()}
            except ValueError:
                messagebox.showerror("Invalid Input", "Data loss IDs must be comma-separated integers.")
                return None

        # Parse ACK Losses
        raw_ack = self.ent_ack_loss.get().strip()
        ack_losses = set()
        if raw_ack and raw_ack != "0":
            try:
                ack_losses = {int(x.strip()) for x in raw_ack.split(",") if x.strip()}
            except ValueError:
                messagebox.showerror("Invalid Input", "ACK loss IDs must be comma-separated integers.")
                return None

        try:
            timeout = float(self.ent_timeout.get().strip() or "2.0")
            if timeout <= 0:
                raise ValueError()
        except ValueError:
            messagebox.showerror("Invalid Input", "Timeout must be a positive number.")
            return None

        return count, data_losses, ack_losses, timeout

    def start_simulation(self):
        if self.is_running and self.is_paused:
            # Resume from pause
            self.is_paused = False
            self.btn_pause.config(text="⏸ Pause")
            self.status_lbl.config(text="Status: Running", fg=ACCENT_GREEN)
            self._animate_loop()
            return

        params = self._parse_inputs()
        if not params:
            return

        count, data_losses, ack_losses, timeout = params
        self.reset_all()

        # Generate event trace
        try:
            self.events = simulate(
                packet_count=count,
                data_losses=data_losses,
                ack_losses=ack_losses,
                timeout=timeout,
                data_time=0.5,
                ack_time=0.25
            )
        except Exception as exc:
            messagebox.showerror("Simulation Error", str(exc))
            return

        self.is_running = True
        self.is_paused = False
        self.current_event_idx = -1
        self.btn_run.config(state=tk.DISABLED)
        self.btn_pause.config(state=tk.NORMAL, text="⏸ Pause")
        self.status_lbl.config(text=f"Status: Simulating {count} packets...", fg=ACCENT_BLUE)

        # Redraw axes to fit all events
        self._draw_ladder_axes()
        self.step_next_event()

    def toggle_pause(self):
        if not self.is_running:
            return
        self.is_paused = not self.is_paused
        if self.is_paused:
            self.btn_pause.config(text="▶ Resume")
            self.status_lbl.config(text="Status: Paused", fg=ACCENT_AMBER)
        else:
            self.btn_pause.config(text="⏸ Pause")
            self.status_lbl.config(text="Status: Running", fg=ACCENT_GREEN)
            self._animate_loop()

    def inject_data_drop(self):
        self.inject_drop_data = True
        self.status_lbl.config(text="💥 Fault Injected: Next DATA packet will be dropped!", fg=ACCENT_RED)

    def inject_ack_drop(self):
        self.inject_drop_ack = True
        self.status_lbl.config(text="💥 Fault Injected: Next ACK packet will be dropped!", fg=ACCENT_AMBER)

    def step_next_event(self):
        if not self.events:
            params = self._parse_inputs()
            if not params:
                return
            count, data_losses, ack_losses, timeout = params
            self.events = simulate(count, data_losses, ack_losses, timeout)
            self._draw_ladder_axes()

        if self.current_event_idx + 1 >= len(self.events):
            self.is_running = False
            self.btn_run.config(state=tk.NORMAL, text="▶ RE-RUN")
            self.btn_pause.config(state=tk.DISABLED)
            self.status_lbl.config(text="Status: Completed all packets!", fg=ACCENT_GREEN)
            self._draw_channel_background(sender_state="IDLE", receiver_state="ACCEPTED", seq_num="0", timer_pct=0.0)
            return

        self.current_event_idx += 1
        event = self.events[self.current_event_idx]
        self._process_event(event)

    def _process_event(self, event: Event):
        # Check dynamic error injection
        is_lost = event.status.startswith("LOST")
        if self.inject_drop_data and event.packet_type == "DATA" and not is_lost:
            is_lost = True
            self.inject_drop_data = False
        if self.inject_drop_ack and event.packet_type == "ACK" and not is_lost:
            is_lost = True
            self.inject_drop_ack = False

        seq = str(event.packet_id % 2)

        # Update stats
        tag = "DATA_OK"
        if event.packet_type == "DATA":
            if "retry" in event.status:
                self.stat_retries += 1
                tag = "RETRY"
            else:
                self.stat_sent += 1
            if is_lost:
                self.stat_data_lost += 1
                tag = "LOST"
        elif event.packet_type == "ACK":
            if is_lost:
                self.stat_ack_lost += 1
                tag = "LOST"
            else:
                self.stat_delivered = max(self.stat_delivered, event.packet_id)
                tag = "ACK_OK"
        elif event.packet_type == "TIMEOUT":
            self.stat_timeouts += 1
            tag = "TIMEOUT"

        self._update_stat_cards()

        # Add row to Event Log Treeview
        item_id = self.tree_log.insert("", tk.END, values=(
            f"{event.start:.2f}s",
            f"#{event.packet_id}",
            event.packet_type,
            event.status
        ), tags=(tag,))
        self.tree_log.see(item_id)

        # Draw onto Space-Time Ladder Diagram
        self._add_ladder_event(event, self.current_event_idx, is_lost)

        # Trigger animated packet transfer
        self._start_packet_animation(event, seq, is_lost)

    def _add_ladder_event(self, event: Event, index: int, is_lost: bool):
        c = self.ladder_canvas
        w = c.winfo_width()
        x_sender = 120
        x_receiver = w - 120

        # Vertical position for this event row
        y_start = 50 + index * 42
        y_end = y_start + 32

        # Auto-scroll ladder down as events occur
        c.yview_moveto(min(1.0, (y_start - 100) / max(1, c.bbox("all")[3] if c.bbox("all") else 500)))

        seq = str(event.packet_id % 2)

        if event.packet_type == "DATA":
            if is_lost:
                x_mid = (x_sender + x_receiver) / 2
                y_mid = (y_start + y_end) / 2
                c.create_line(x_sender, y_start, x_mid, y_mid, fill=ACCENT_RED, width=2, dash=(4, 2))
                c.create_text(x_mid, y_mid, text="❌ LOST", fill=ACCENT_RED, font=("Segoe UI", 8, "bold"))
                c.create_text(x_sender + 45, y_start - 8, text=f"DATA {event.packet_id} (Seq {seq})", fill=ACCENT_BLUE, font=("Segoe UI", 7))
            else:
                retry_txt = " [RETRY]" if "retry" in event.status else ""
                c.create_line(x_sender, y_start, x_receiver, y_end, fill=ACCENT_BLUE, width=2, arrow=tk.LAST)
                c.create_text((x_sender + x_receiver) / 2, (y_start + y_end) / 2 - 8,
                              text=f"DATA {event.packet_id} (Seq {seq}){retry_txt}", fill=ACCENT_BLUE, font=("Segoe UI", 8))
                c.create_oval(x_receiver - 3, y_end - 3, x_receiver + 3, y_end + 3, fill=ACCENT_GREEN, outline="")

        elif event.packet_type == "ACK":
            if is_lost:
                x_mid = (x_receiver + x_sender) / 2
                y_mid = (y_start + y_end) / 2
                c.create_line(x_receiver, y_start, x_mid, y_mid, fill=ACCENT_RED, width=2, dash=(4, 2))
                c.create_text(x_mid, y_mid, text="❌ LOST", fill=ACCENT_RED, font=("Segoe UI", 8, "bold"))
                c.create_text(x_receiver - 45, y_start - 8, text=f"ACK {event.packet_id}", fill=ACCENT_GREEN, font=("Segoe UI", 7))
            else:
                c.create_line(x_receiver, y_start, x_sender, y_end, fill=ACCENT_GREEN, width=2, arrow=tk.LAST)
                c.create_text((x_sender + x_receiver) / 2, (y_start + y_end) / 2 - 8,
                              text=f"ACK {event.packet_id}", fill=ACCENT_GREEN, font=("Segoe UI", 8))
                c.create_oval(x_sender - 3, y_end - 3, x_sender + 3, y_end + 3, fill=ACCENT_BLUE, outline="")

        elif event.packet_type == "TIMEOUT":
            # Timeout bracket on Sender axis
            c.create_line(x_sender - 8, y_start, x_sender - 16, y_start,
                          x_sender - 16, y_end, x_sender - 8, y_end, fill=ACCENT_AMBER, width=2)

                          text=f"⏱️ Timeout\n({event.end - event.start:.1f}s)", fill=ACCENT_AMBER, font=("Segoe UI", 7, "bold"))

    def _start_packet_animation(self, event: Event, seq: str, is_lost: bool):
        self.anim_event = event
        self.anim_seq = seq
        self.anim_lost = is_lost
        self.anim_step = 0
        self.anim_total_steps = max(10, int(28 / self.speed_multiplier))
        self._animate_loop()

    def _animate_loop(self):
        if not self.is_running or self.is_paused:
            return

        c = self.canvas_channel
        w = c.winfo_width()
        node_w = 150
        y_top = 30
        x_s2 = 20 + node_w
        x_r1 = w - 20 - node_w

        ev = self.anim_event
        is_data = (ev.packet_type == "DATA")
        is_ack = (ev.packet_type == "ACK")
        is_timeout = (ev.packet_type == "TIMEOUT")

        if is_timeout:
            # Handle timeout event animation: flash timer on sender
            progress = self.anim_step / self.anim_total_steps
            self._draw_channel_background(
                sender_state="TIMEOUT",
                receiver_state="IDLE",
                seq_num=self.anim_seq,
                timer_pct=min(1.0, progress * 1.2)
            )
            self.anim_step += 1
            if self.anim_step <= self.anim_total_steps:
                self.root.after(25, self._animate_loop)
            else:
                self.step_next_event()
            return

        # Packet flight progress: 0.0 to 1.0
        progress = self.anim_step / self.anim_total_steps

        # Check if dropped packet should stop midway
        stop_at_loss = 0.55
        if self.anim_lost and progress >= stop_at_loss:
            # Drop packet!
            if is_data:
                drop_x = x_s2 + (x_r1 - x_s2) * stop_at_loss
                drop_y = y_top + 55
            else:
                drop_x = x_r1 - (x_r1 - x_s2) * stop_at_loss
                drop_y = y_top + 125

            self._spawn_explosion(drop_x, drop_y, ACCENT_RED)
            self._draw_channel_background(
                sender_state="WAITING_ACK" if is_data else "WAITING_ACK",
                receiver_state="IDLE" if is_data else "IDLE",
                seq_num=self.anim_seq,
                timer_pct=0.6
            )
            # Draw dropped explosion badge
            c.create_rectangle(drop_x - 45, drop_y - 14, drop_x + 45, drop_y + 14,
                               fill="#7f1d1d", outline=ACCENT_RED, width=2)
            c.create_text(drop_x, drop_y, text="💥 PACKET DROPPED", fill="white", font=("Segoe UI", 7, "bold"))

            # Step after short pause
            self.root.after(int(350 / self.speed_multiplier), self.step_next_event)
            return

        # Normal flight or pre-drop flight
        if is_data:
            current_x = x_s2 + 10 + (x_r1 - x_s2 - 80) * progress
            current_y = y_top + 55
            self._draw_channel_background(
                sender_state="RETRANSMITTING" if "retry" in ev.status else "SENDING",
                receiver_state="IDLE",
                seq_num=self.anim_seq,
                timer_pct=progress * 0.4
            )
            # Draw moving DATA packet capsule
            c.create_rectangle(current_x - 38, current_y - 14, current_x + 38, current_y + 14,
                               fill="#0369a1", outline=ACCENT_BLUE, width=2)
            c.create_text(current_x, current_y - 2, text=f"DATA #{ev.packet_id}", fill="white", font=("Segoe UI", 8, "bold"))
            c.create_text(current_x, current_y + 9, text=f"Seq: {self.anim_seq}", fill=ACCENT_BLUE, font=("Segoe UI", 6))

        elif is_ack:
            current_x = (x_r1 - 10) - (x_r1 - x_s2 - 80) * progress
            current_y = y_top + 125
            self._draw_channel_background(
                sender_state="WAITING_ACK",
                receiver_state="SENDING ACK",
                seq_num=self.anim_seq,
                timer_pct=0.4 + progress * 0.3
            )
            # Draw moving ACK packet capsule
            c.create_rectangle(current_x - 30, current_y - 12, current_x + 30, current_y + 12,
                               fill="#065f46", outline=ACCENT_GREEN, width=2)
            c.create_text(current_x, current_y, text=f"ACK #{ev.packet_id}", fill="white", font=("Segoe UI", 8, "bold"))

        self.anim_step += 1
        if self.anim_step <= self.anim_total_steps:
            self.root.after(25, self._animate_loop)
        else:
            # Reached destination!
            if is_data:
                self._draw_channel_background(
                    sender_state="WAITING_ACK",
                    receiver_state="ACCEPTED",
                    seq_num=self.anim_seq,
                    timer_pct=0.5
                )
            elif is_ack:
                self._draw_channel_background(
                    sender_state="ACK RECEIVED",
                    receiver_state="IDLE",
                    seq_num=self.anim_seq,
                    timer_pct=0.0
                )
            self.root.after(int(100 / self.speed_multiplier), self.step_next_event)

Why are two sequence numbers enough?

Only one frame is outstanding. The next new frame must have the other number, so a retransmission cannot be confused with a new frame.

What if the timeout is shorter than the real round trip?

The sender retransmits a frame whose ACK is still on the way. You get duplicates even when nothing was lost.

Data loss versus ACK loss, from the sender’s point of view?

They look the same: the timer expires. The sender cannot tell which one happened. It retransmits either way.
